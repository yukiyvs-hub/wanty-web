# わんてぃ MVP

ペットオーナーが犬種・地域・悩み・おでかけ目的ごとのコミュニティに参加し、体験投稿やスポット情報から「うちの子に合う人・場所・情報」を見つけるためのWebサイトMVPです。

## 主なページ

- `/` トップページ
- `/communities` コミュニティ一覧
- `/communities/toy-poodle` コミュニティ詳細
- `/posts` 体験投稿一覧
- `/spots` スポット一覧
- `/spots/s1` スポット詳細
- `/articles` 記事一覧
- `/mypage` マイページ
- `/business` 事業者向け

## 実行

依存関係なしで今すぐ見る場合は、`open-preview.cmd` を開くか、`preview.html` をブラウザで開いてください。

```bash
npm install
npm run dev
```
